Macro maker
- GUI displays the list of steps in the Macro
- Includes if/else statement options that you close with ENDIF statements
- Includes key hold/press/release options
- Includes mouse click/hold/move/release options (You're able to place your mouse in the area you want it to do this and saving that position when prompted for where to do a mouse command)
- Image capture capability, capable of doing IF IMAGE commands or FIND IMAGE commands
- Macros are saved in a list in the GUI, in a dropdown menu at the top to select which one you want to run, with a "repeat" field that determines how many times the macro is to be run, if 0 is entered here it runs over and over again indefinitely.
- All macros have configurable system-wide hotkeys, you specify this with a button in the GUI that you can click, it listens for what keys you press, then waits for you to click "Ok," with your mouse to assign that as the hotkey. 
- The app listens across the system when open for any of the assigned hotkeys for any of the macros in the dropdown menu, if the hotkey for any particular macro is pressed, it changes the dropdown selection to that macro automatically
- Macros saved in the GUI are preserved between sessions and reboots, are editable when selected, and there is a delete button in the GUI to delete the currently selected macro.
- Also include repeat statements
